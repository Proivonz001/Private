# Private

Progetto in fase iniziale: contenuto e stack tecnologico non sono ancora stati definiti.

## Convenzioni

- Tutti i file di testo usano fine riga LF (`.gitattributes`); codifica, indentazione e spazi finali seguono `.editorconfig`.
- Segreti e configurazioni locali (`.env`, `.env.*`) sono esclusi da git. Per documentare le variabili necessarie si usa un `.env.example` senza valori reali.
